Sincronização com a Planilha Google Sheets

Integração em tempo real com a planilha e criação de atalho HTTPS na tela inicial

📱 Como ativar "Adicionar à tela inicial" nos 3 pontinhos (⋮) do Chrome com o Ícone Oficial H&L:

Por que a opção não aparece nos 3 pontinhos em arquivos locais: O Google Chrome para Android oculta obrigatoriamente a opção "Adicionar à tela inicial / Instalar aplicativo" sempre que o endereço no topo começa com content:// ou file:// (arquivo aberto da memória do celular). O Chrome só libera essa opção nos 3 pontinhos quando o arquivo é aberto por um link https://.

Passo a passo rápido para gerar seu link HTTPS gratuito pelo celular:
1. Baixe o arquivo .html já com a sua URL do Apps Script embutida (botão marrom no rodapé desta janela).
2. Acesse gratuitamente tiiny.host ou app.netlify.com/drop no navegador do celular e envie o arquivo .html.
3. Abra o link https://... gerado no Google Chrome, toque nos 3 pontinhos (⋮) no canto superior direito e toque em "Adicionar à tela inicial" (ou "Instalar aplicativo"). O atalho será criado com o ícone redondo oficial das alianças douradas H&L!

1 Leitura Automática do Link da Planilha (Já Configurada!)

Esta aplicação já traz embutido no código o link oficial da sua planilha. Sempre que você ou a Laís abrirem o arquivo HTML em qualquer celular ou computador (mesmo sem salvar nada localmente), o app busca os dados ao vivo diretamente da planilha (basta que no Google Sheets o compartilhamento esteja como "Qualquer pessoa com o link pode visualizar/editar").

2 Ativar Gravação Automática na Planilha (Google Apps Script)

Para que o botão "Adicionar Convidado" insira linhas automaticamente dentro da sua planilha Google:

  1. Abra sua Planilha de Convidados no computador e clique no menu superior Extensões > Apps Script.
  2. Apague qualquer código que estiver lá, cole o código abaixo e clique no ícone de Salvar (Disquete).
  3. Clique no botão azul Implantar > Nova implantação, clique na engrenagem ⚙️ ao lado de "Selecionar tipo" e escolha App da Web.
  4. Em "Quem pode acessar" selecione Qualquer pessoa (muito importante para não dar erro de bloqueio!) e clique em Implantar.
  5. Copie a URL do App da Web (que termina em /exec) e cole no campo abaixo. Depois clique em "Baixar .HTML com esta URL Embutida"!

📱 Como configurar o Apps Script 100% pelo Celular (Android ou iPhone):

O aplicativo "Planilhas Google" do celular esconde o menu Extensões, mas você consegue fazer pelo navegador Chrome ou Safari seguindo este truque simples:

  1. Abra o navegador Chrome (Android) ou Safari (iPhone) e abra uma guia qualquer.
  2. Ative o modo computador: no Chrome toque nos 3 pontinhos (⋮) no topo e marque "Para computador" (Site para Desktop). No Safari toque em AA na barra de endereço e escolha "Solicitar Site para Computador".
  3. Cole na barra de endereços este link exato da sua planilha:
    https://docs.google.com/spreadsheets/d/1_w4UCIG0wmtXetsUxItOqN9zbno7JE7IWcXPGwu4oag/edit 💡 Dica: Se o celular tentar abrir o aplicativo do Planilhas, segure o dedo sobre o link e toque em "Abrir em nova guia no grupo".
  4. Com a planilha aberta em modo computador no navegador, dê um zoom com os dedos no menu do topo e toque em Extensões > Apps Script.
  5. Toque em "Copiar Código Apps Script" abaixo, apague o código antigo lá no editor, cole o código novo e toque no ícone de Disquete (Salvar).
  6. No topo direito do Apps Script, toque em Implantar > Nova implantação, escolha App da Web, mude "Quem pode acessar" para Qualquer pessoa e confirme.
  7. Copie a URL gerada (terminada em /exec) e cole na caixa abaixo!

const SHEET_ID = '1_w4UCIG0wmtXetsUxItOqN9zbno7JE7IWcXPGwu4oag';

function getTargetSheet() {
  const ss = SpreadsheetApp.openById(SHEET_ID);
  const sheet = ss.getSheets()[0];
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(['Nome', 'Sobrenome', 'Relação com os Noivos', 'Especificação (Outros)', 'Celular / WhatsApp', 'Instagram', 'Tem Acompanhante', 'Data de Inclusão', 'Cidade', 'Especificação Cidade (Outros)']);
  }
  return sheet;
}

// Remove linhas em branco e mantém acompanhantes e crianças logo abaixo do respectivo titular na planilha!
function compactAndOrderSheet(sheet) {
  const lastRow = sheet.getLastRow();
  if (lastRow <= 1) return;
  const allValues = sheet.getRange(1, 1, lastRow, 10).getValues();
  const header = allValues[0];
  const validRows = [];

  for (let i = 1; i < allValues.length; i++) {
    const r = allValues[i];
    const nome = String(r[0] || '').trim();
    const sobrenome = String(r[1] || '').trim();
    if (!nome && !sobrenome) continue;
    if (nome.toLowerCase() === 'nome' && sobrenome.toLowerCase() === 'sobrenome') continue;
    if (nome.indexOf('__SLOT_') === 0) continue;
    validRows.push(r);
  }

  const norm = function(s) { return String(s || '').trim().toLowerCase(); };
  const titulars = [];
  const guestChildrenByHost = {};
  const compsByHost = {};
  const compChildrenByComp = {};

  validRows.forEach(function(r) {
    const rel = String(r[2] || '').trim();
    const acompCol = String(r[6] || '').trim();
    const childMatch = acompCol.match(/^crian[cç]a\s+de\s+(?:convidado|acompanhante)?\s*:?\s*(.+?)(?:\s*\(\d+\s*anos?\))?$/i);
    const compMatch = acompCol.match(/^acompanhante\s+de\s*:?\s*(.+)$/i);

    if (childMatch) {
      const parentKey = norm(childMatch[1]);
      if (rel.toLowerCase().indexOf('acompanhante') !== -1 || acompCol.toLowerCase().indexOf('criança de acompanhante') === 0) {
        if (!compChildrenByComp[parentKey]) compChildrenByComp[parentKey] = [];
        compChildrenByComp[parentKey].push(r);
      } else {
        if (!guestChildrenByHost[parentKey]) guestChildrenByHost[parentKey] = [];
        guestChildrenByHost[parentKey].push(r);
      }
    } else if (compMatch) {
      const hostKey = norm(compMatch[1]);
      if (!compsByHost[hostKey]) compsByHost[hostKey] = [];
      compsByHost[hostKey].push(r);
    } else {
      titulars.push(r);
    }
  });

  const ordered = [];
  const usedGuestCh = {};
  const usedComps = {};
  const usedCompCh = {};

  titulars.forEach(function(t) {
    ordered.push(t);
    const tKey = norm(t[0] + ' ' + t[1]);
    if (guestChildrenByHost[tKey]) {
      usedGuestCh[tKey] = true;
      guestChildrenByHost[tKey].forEach(function(ch) { ordered.push(ch); });
    }
    if (compsByHost[tKey]) {
      usedComps[tKey] = true;
      compsByHost[tKey].forEach(function(c) {
        ordered.push(c);
        const cKey = norm(c[0] + ' ' + c[1]);
        if (compChildrenByComp[cKey]) {
          usedCompCh[cKey] = true;
          compChildrenByComp[cKey].forEach(function(cch) { ordered.push(cch); });
        }
        if (guestChildrenByHost[cKey] && !usedGuestCh[cKey]) {
          usedGuestCh[cKey] = true;
          guestChildrenByHost[cKey].forEach(function(cch) { ordered.push(cch); });
        }
      });
    }
  });

  Object.keys(guestChildrenByHost).forEach(function(k) {
    if (!usedGuestCh[k]) guestChildrenByHost[k].forEach(function(ch) { ordered.push(ch); });
  });
  Object.keys(compsByHost).forEach(function(k) {
    if (!usedComps[k]) compsByHost[k].forEach(function(c) { ordered.push(c); });
  });
  Object.keys(compChildrenByComp).forEach(function(k) {
    if (!usedCompCh[k]) compChildrenByComp[k].forEach(function(cch) { ordered.push(cch); });
  });

  sheet.clearContents();
  const finalMatrix = [header].concat(ordered);
  sheet.getRange(1, 1, finalMatrix.length, 10).setValues(finalMatrix);
}

function doGet(e) {
  const sheet = getTargetSheet();
  if (e && e.parameter && e.parameter.action === 'add') {
    sheet.appendRow([
      e.parameter.nome || '',
      e.parameter.sobrenome || '',
      e.parameter.relacao || '',
      e.parameter.outros || '',
      e.parameter.whatsapp || '',
      e.parameter.instagram || '',
      e.parameter.acompanhante || 'Não',
      new Date().toLocaleString('pt-BR'),
      e.parameter.cidade || '',
      ''
    ]);
    compactAndOrderSheet(sheet);
  } else if (e && e.parameter && e.parameter.action === 'delete') {
    const allRows = sheet.getDataRange().getValues();
    const origNome = (e.parameter.origNome || '').trim().toLowerCase();
    const origSobrenome = (e.parameter.origSobrenome || '').trim().toLowerCase();
    for (let r = allRows.length - 1; r >= 1; r--) {
      if (String(allRows[r][0] || '').trim().toLowerCase() === origNome &&
          String(allRows[r][1] || '').trim().toLowerCase() === origSobrenome) {
        sheet.deleteRow(r + 1);
        break;
      }
    }
    compactAndOrderSheet(sheet);
  } else if (e && e.parameter && e.parameter.action === 'edit') {
    const allRows = sheet.getDataRange().getValues();
    const origNome = (e.parameter.origNome || '').trim().toLowerCase();
    const origSobrenome = (e.parameter.origSobrenome || '').trim().toLowerCase();
    for (let r = 1; r < allRows.length; r++) {
      if (String(allRows[r][0] || '').trim().toLowerCase() === origNome &&
          String(allRows[r][1] || '').trim().toLowerCase() === origSobrenome) {
        sheet.getRange(r + 1, 1, 1, 10).setValues([[
          e.parameter.nome || '',
          e.parameter.sobrenome || '',
          e.parameter.relacao || '',
          e.parameter.outros || '',
          e.parameter.whatsapp || '',
          e.parameter.instagram || '',
          e.parameter.acompanhante || '',
          new Date().toLocaleString('pt-BR'),
          e.parameter.cidade || '',
          ''
        ]]);
        break;
      }
    }
    if (!e.parameter.skipCompact) {
      compactAndOrderSheet(sheet);
    }
  }
  const rows = sheet.getDataRange().getValues();
  const payload = JSON.stringify({ ok: true, rows: rows });
  if (e && e.parameter && e.parameter.callback) {
    return ContentService.createTextOutput(e.parameter.callback + '(' + payload + ');')
      .setMimeType(ContentService.MimeType.JAVASCRIPT);
  }
  return ContentService.createTextOutput(payload)
    .setMimeType(ContentService.MimeType.JSON);
}

v2.4.0 — Versão Atual Release Atual
  • Seleção de Padrinho e Madrinha (Do Noivo / Da Noiva): Menu drop-down para indicar se o convidado (ou acompanhante) será Madrinha ou Padrinho, abrindo checkboxes para marcar se é do Noivo (Hans) ou da Noiva (Laís).
  • Painel de Contagem de Padrinhos e Madrinhas: Novo cartão de estatísticas na aplicação e no PDF mostrando quantos padrinhos e madrinhas cada noivo tem.

v2.3.0 Feature & Fix Release

v2.2.0 Feature Release
